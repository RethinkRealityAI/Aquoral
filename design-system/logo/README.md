# Aquoral logo (official, Brand Guidelines 2025)

Vector SVGs traced (potrace, 4-6x upscale) from the client's artwork: `Aquoral-logo-transparent.png` and the
secondary logo in `Aquoral- Brand Guidelines - 1.23.25.pdf` (2026-11-16). Colours snapped to the guideline values.

| File | Use |
| --- | --- |
| aquoral-logo-primary(.svg / -white.svg) | Primary logo: mark, wordmark, "artificial saliva", "PROTECTIVE ORAL SPRAY". Footer, print, large placements. |
| aquoral-logo-secondary(.svg / -white.svg) | Secondary logo: mark above wordmark. Header, small spaces. |
| aquoral-mark(.svg / -white.svg) | Magenta dot, bar, tgo circle only. |
| aquoral-wordmark(.svg / -white.svg) | Wordmark with ®. |
| aquoral-tgo.svg | tgo circle on a white disc, used for the favicon set. |

Brand colours: primary #E2188F (magenta), #044F7C (blue), #FFFFFF, #000000; secondary #52D9F1, #9DA7B1, #E1C93A, #54575A (logo grey).
Approved variants: full colour on light grounds, all-white reversal on dark grounds, grey. Never recolour, rotate, stretch,
blur, add shadows, or move the mark to the right of or below the wordmark. Typeface: Poppins (secondary: Goudy, not used on the site).
